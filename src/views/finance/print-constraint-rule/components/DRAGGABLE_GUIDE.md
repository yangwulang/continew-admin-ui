# 拖拽式条件配置器使用指南

## 🎨 设计理念

将传统的表单配置升级为**拖拽式可视化界面**，让用户通过直观的拖拽操作来构建复杂的规则条件。

## ✨ 核心特性

### 1. 拖拽排序
- ✅ **自由拖拽**：按住条件卡片左侧的拖拽图标（⋮⋮）即可拖动
- ✅ **视觉反馈**：拖拽时显示半透明效果和目标位置高亮
- ✅ **流畅动画**：200ms 过渡动画，体验更自然

### 2. 条件管理
- ✅ **快速添加**：点击底部"添加条件"按钮
- ✅ **一键复制**：点击条件卡片右上角的复制图标
- ✅ **便捷删除**：点击条件卡片右上角的删除图标

### 3. 逻辑关系可视化
- ✅ **连接符显示**：条件之间显示 AND/OR 连接符
- ✅ **连线效果**：垂直连接线清晰展示条件关系
- ✅ **颜色区分**：AND（蓝色）、OR（橙色）

### 4. 智能表单
- ✅ **属性图标**：每个属性都有对应的图标标识
- ✅ **动态输入**：根据操作符自动切换单值/多值输入
- ✅ **常用值提示**：IN/NOT_IN 操作符显示常用值标签

### 5. JSON 预览（可选）
- ✅ **实时预览**：展开查看生成的 JSON 配置
- ✅ **代码高亮**：使用 CodeView 组件美化显示

## 🎯 使用步骤

### 第一步：选择逻辑关系
在顶部选择条件的组合方式：
- **全部满足（AND）**：所有条件都必须为真
- **任一满足（OR）**：任意一个条件为真即可

### 第二步：添加条件
1. 点击底部的 **"+ 添加条件"** 按钮
2. 新条件会自动添加到列表末尾

### 第三步：配置条件
对每个条件进行配置：

#### 3.1 选择属性
点击属性下拉框，选择要判断的属性：
- 📄 **纸张尺寸** (PAPER_SIZE)
- ✂️ **装订方式** (BINDING_TYPE)
- 🖨️ **打印模式** (PRINT_MODE)
- 🔢 **页数** (PAGE_COUNT)
- 📦 **份数** (COPIES)

#### 3.2 选择操作符
根据需求选择合适的操作符：
- **等于** (EQ) - 精确匹配
- **不等于** (NE) - 排除匹配
- **包含于** (IN) - 在列表中
- **不包含于** (NOT_IN) - 不在列表中
- **大于** (GT) - 数值比较
- **大于等于** (GTE)
- **小于** (LT)
- **小于等于** (LTE)

#### 3.3 输入值
- **单值操作符**（EQ/NE/GT等）：直接输入单个值
- **多值操作符**（IN/NOT_IN）：输入多个值，按回车添加

### 第四步：调整顺序（可选）
如果需要调整条件的执行顺序：
1. 将鼠标移到条件卡片左侧的 **⋮⋮** 图标上
2. 按住鼠标左键拖动到目标位置
3. 释放鼠标完成排序

### 第五步：复制条件（可选）
如果多个条件相似：
1. 点击条件卡片右上角的 **📋** 复制图标
2. 会在当前条件下方创建一个副本
3. 修改副本中的值即可

### 第六步：删除条件（可选）
如果不需要某个条件：
1. 点击条件卡片右上角的 **🗑️** 删除图标
2. 确认删除（无二次确认，请谨慎操作）

## 💡 使用示例

### 示例 1：A2及以上纸张禁止骑马订

**配置步骤**：
1. 逻辑关系：选择 **全部满足（AND）**
2. 添加条件 1：
   - 属性：**纸张尺寸**
   - 操作符：**包含于**
   - 值：`A2`, `A1`, `A0`（输入后按回车）
3. 动作配置（在 ActionConfigurator 中）：
   - 动作类型：**禁止选项**
   - 目标属性：**装订方式**
   - 禁止的值：`SADDLE_STITCH`
   - 错误提示：A2及以上纸张不支持骑马订

**生成的 JSON**：
```json
{
  "conditions": [
    {
      "attribute_code": "PAPER_SIZE",
      "operator": "IN",
      "values": ["A2", "A1", "A0"]
    }
  ],
  "logic": "AND"
}
```

### 示例 2：大纸张胶装加价 + 超过500页禁止双面

**配置步骤**：
1. 逻辑关系：选择 **全部满足（AND）**
2. 添加条件 1：
   - 属性：**纸张尺寸**
   - 操作符：**包含于**
   - 值：`A2`, `A1`, `A0`
3. 点击 **添加条件**
4. 添加条件 2：
   - 属性：**装订方式**
   - 操作符：**等于**
   - 值：`GLUE`
5. 点击 **添加条件**
6. 添加条件 3：
   - 属性：**页数**
   - 操作符：**大于**
   - 值：`500`

**生成的 JSON**：
```json
{
  "conditions": [
    {
      "attribute_code": "PAPER_SIZE",
      "operator": "IN",
      "values": ["A2", "A1", "A0"]
    },
    {
      "attribute_code": "BINDING_TYPE",
      "operator": "EQ",
      "value": "GLUE"
    },
    {
      "attribute_code": "PAGE_COUNT",
      "operator": "GT",
      "value": 500
    }
  ],
  "logic": "AND"
}
```

### 示例 3：A4胶装或A3订书机钉（OR 关系）

**配置步骤**：
1. 逻辑关系：选择 **任一满足（OR）**
2. 添加条件 1：
   - 属性：**纸张尺寸**
   - 操作符：**等于**
   - 值：`A4`
3. 点击 **添加条件**
4. 添加条件 2：
   - 属性：**装订方式**
   - 操作符：**等于**
   - 值：`STAPLER`

**生成的 JSON**：
```json
{
  "conditions": [
    {
      "attribute_code": "PAPER_SIZE",
      "operator": "EQ",
      "value": "A4"
    },
    {
      "attribute_code": "BINDING_TYPE",
      "operator": "EQ",
      "value": "STAPLER"
    }
  ],
  "logic": "OR"
}
```

## 🎨 交互细节

### 拖拽体验
- **拖拽手柄**：条件卡片左侧的 **⋮⋮** 图标
- **悬停效果**：鼠标悬停时图标变为主题色
- **拖拽状态**：
  - 被拖拽的卡片：半透明（opacity: 0.5）
  - 目标位置：阴影加深
- **动画时长**：200ms，流畅自然

### 卡片交互
- **悬停高亮**：鼠标悬停时边框变为主题色浅蓝
- **阴影效果**：悬停时显示轻微阴影
- **响应式布局**：自适应不同屏幕宽度

### 表单交互
- **级联清空**：切换操作符时，自动清空之前的值
- **输入提示**：placeholder 提供清晰的输入指引
- **清除按钮**：所有输入框都支持一键清空

## 🔧 技术实现

### 依赖库
```json
{
  "vue-draggable-plus": "^0.3.5"
}
```

### 核心代码
```vue
<draggable
  v-model="localConfig.conditions"
  item-key="index"
  handle=".drag-handle"
  animation="200"
  ghost-class="drag-ghost"
  chosen-class="drag-chosen"
  @end="onDragEnd"
>
  <template #item="{ element: condition, index }">
    <!-- 条件卡片内容 -->
  </template>
</draggable>
```

### 关键属性说明
- `v-model`：双向绑定的条件数组
- `item-key`：每项的唯一标识
- `handle`：拖拽手柄的 CSS 类名
- `animation`：拖拽动画时长（毫秒）
- `ghost-class`：拖拽时的占位符样式
- `chosen-class`：选中状态的样式

## 🚀 性能优化

1. **虚拟滚动**：当条件数量超过 100 时考虑启用
2. **防抖处理**：JSON 序列化使用 watch + deep，避免频繁计算
3. **懒加载图标**：仅在实际使用时导入图标组件

## 📝 注意事项

1. **拖拽限制**：只能在条件列表内拖拽，不能拖出边界
2. **数据同步**：拖拽后立即更新数组顺序，JSON 自动同步
3. **复制功能**：复制的是深拷贝，修改副本不影响原条件
4. **删除警告**：删除操作无二次确认，请谨慎点击
5. **必填验证**：提交时会验证每个条件的完整性

## 🎯 最佳实践

### 1. 条件命名规范
虽然界面上显示"条件 1"、"条件 2"，但建议在规则描述中说明每个条件的含义：
```
规则描述：A2及以上纸张且使用胶装时，价格调整为1.5倍
- 条件1：纸张尺寸为 A2/A1/A0
- 条件2：装订方式为胶装
```

### 2. 逻辑关系选择
- **AND**：适用于需要同时满足多个条件的场景
- **OR**：适用于满足任一条件即可的场景

### 3. 操作符选择
- 精确匹配 → EQ/NE
- 范围匹配 → IN/NOT_IN
- 数值比较 → GT/GTE/LT/LTE

### 4. 条件顺序
- 将**筛选性最强**的条件放在前面（如纸张尺寸）
- 将**筛选性较弱**的条件放在后面（如页数）

## 📞 常见问题

### Q1: 拖拽没有反应？
**A**: 确保鼠标准确点击在 **⋮⋮** 拖拽图标上，而不是卡片其他区域。

### Q2: 如何快速创建相似条件？
**A**: 使用条件卡片右上角的 **📋** 复制按钮，然后修改需要的字段。

### Q3: JSON 格式不正确？
**A**: 检查是否有未填写的字段，特别是操作符为 IN/NOT_IN 时必须输入至少一个值。

### Q4: 能否隐藏 JSON 预览？
**A**: 可以，不传递 `show-preview` 属性即可：
```vue
<ConditionConfigurator v-model="formData.conditionConfig" />
```

如需显示预览：
```vue
<ConditionConfigurator 
  v-model="formData.conditionConfig" 
  :show-preview="true" 
/>
```
